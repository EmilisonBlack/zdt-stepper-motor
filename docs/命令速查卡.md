# ZDT_X_V2 命令速查卡

> 一句话速查: `P_Serial=UART_FUN`, `Response=Receive`, `Checksum=0x6B`, 波特率=115200

---

## 读参数 (发送 3 字节, 接收变长)

| 命令 | 功能 | 发送 | 响应解析 |
|------|------|------|---------|
| `01 1F 6B` | 读版本 | ✅ | ASCII 版本字符串, `C9`=V2.0.1 |
| `01 24 6B` | 读电压 | ✅ | `[mV_H][mV_L]` → mV |
| `01 27 6B` | 读电流 | ✅ | `[mA_H][mA_L]` → mA |
| `01 31 6B` | 读编码器 | ✅ | `[val16]` 0–65535 |
| `01 35 6B` | 读转速 | ✅ | `[dir][val16÷10]` → 0.1 RPM |
| `01 36 6B` | 读位置 | ✅ | `[dir][pos32÷10]` → 0.1° |
| `01 33 6B` | 读目标位置 | ⚠ | **带方向字节**, ÷10 |
| `01 37 6B` | 读位置误差 | ⚠ | **带方向字节**, ÷100 (0.01°) |
| `01 3A 6B` | 读状态 | ✅ | `[flags]` bit0=使能,bit1=到位,bit2=堵转 |
| `01 3B 6B` | 读回零状态 | ✅ | `[status]` bit0=忙,bit1=失败 |

## 控制命令 (发送多字节)

| 命令 | 功能 | 发送 (V2.0 格式) | 成功响应 |
|------|------|------------------|---------|
| **使能** | 0xF3 | `01 F3 AB 01 00 6B` | `01 F3 02 6B` |
| **速度** | 0xF6 | `01 F6 [dir] [acc16] [spd×10] [sync] 6B` **9 字节** | `01 F6 02 6B` |
| **直通位置** | 0xFD | `01 FD [dir] [acc1] [acc2] [spd×10] [pos×10] [abs] [sync] 6B` **16 字节** | `01 FD 02 6B` |
| **停止** | 0xFE | `01 FE 98 [sync] 6B` **5 字节** | `01 FE 02 6B` |
| 同步 | 0xFF | `01 FF 66 6B` | `01 FF 02 6B` |
| 当前清零 | 0x0A | `01 0A 6D 6B` | `01 0A 02 6B` |
| 校准编码器 | 0x06 | `01 06 45 6B` | `01 06 02 6B` |
| 设机械零点 | 0x93 | `01 93 88 [save] 6B` | `01 93 02 6B` |
| 解除堵转 | 0x0E | `01 0E 52 6B` | `01 0E 02 6B` |
| 恢复出厂 | 0x0F | `01 0F 5F 6B` | `01 0F 02 6B` |

> ✅ = 已验证测试通过 | ⚠ = 已验证但需注意解析差异

## V2.0 vs V1.2 速度命令差异 (关键!)

| 版本 | 帧 (不含 0x6B) | 总字节 |
|------|----------------|--------|
| **V1.2** | `[F6][dir][vel_H][vel_L][acc8][sync]` | 7+1=8 |
| **V2.0** | `[F6][dir][acc16_H][acc16_L][vel×10_H][vel×10_L][sync]` | **8+1=9** |

> V2.0 加速度 **16 位**、在速度之前、速度单位 **0.1 RPM**。用 V1.2 格式写会返回 `01 00 EE 6B` 错误！

## 状态标志位 (0x3A)

```
Bit:  7    6    5    4    3    2    1    0
     S_PosTDP  —    —    —  堵转  到位 使能
```

值 `0x03` = 使能 + 到位 | 值 `0x01` = 使能 + 运动中

## 错误响应

```
01 00 EE 6B  ← 命令错误！检查帧格式、字节数、参数范围
```

## OLED 关键设置

```
P_Serial  → UART_FUN   (不是 ESI_ALO!)
Response  → Receive    (不是 None!)
Checksum  → 0x6B       (或用 Modbus)
UartBaud  → 115200
ID_Addr   → 1 (或你设定的值)
```

## 实用速查

- 相电流设置范围: X42=3000mA, X57=4000mA
- 转速范围: 0.1 – 3000.0+ RPM
- 位置范围: ±3600.0° (10 圈)
- 命令间隔: ≥5ms (否则可能被合并为一条错误命令)
- 编码器分辨率: 16384 线
