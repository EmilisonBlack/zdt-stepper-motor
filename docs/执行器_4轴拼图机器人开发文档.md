# 4 轴拼图机器人执行器 — 开发文档

> **项目**: 电赛 E 题 — 拼图装置  
> **硬件**: ZDT_X_V2 闭环步进驱动器 × 4 + 电磁铁吸嘴  
> **协议**: 自定义 0x6B 协议 (Emm_V5.0) / Modbus-RTU  
> **控制模式**: 高精度开环位置控制（非速度环）  
> **最后更新**: 2026-07-30

---

## 1. 系统概述

执行器仿照 3D 打印机运动结构设计，拥有 **4 个自由度**：

| 轴 | 功能 | 说明 |
|----|------|------|
| **X 轴** | 水平横向运动 | 左右移动吸嘴 |
| **Y 轴** | 水平纵向运动 | 前后移动吸嘴 |
| **Z 轴** | 垂直升降运动 | 抬起/放下吸嘴 |
| **R 轴 (旋转)** | 吸嘴旋转 | 调整拼图碎片角度 |

末端执行器将 3D 打印机的挤出喷嘴替换为 **电磁铁**，用于吸取和释放拼图碎片。

```
                     ┌─────────────┐
                     │  Z (升降)   │
                     │  电机 ID:3  │
                     └──────┬──────┘
                            │
              ┌─────────────┴─────────────┐
              │      R (旋转) 电机 ID:4   │
              │    (逆时针为正, 直接角度)  │
              └─────────────┬─────────────┘
                            │
                     ┌──────┴──────┐
                     │   电磁铁    │
                     │  (吸取碎片) │
                     └─────────────┘
              ──── X 轴 (ID:1) ────→
              ════ Y 轴 (ID:2) ════→ (进出纸面)
```

## 2. 电机 ID 分配

| 电机 | 驱动器 ID | 型号参考 | 功能 |
|------|----------|---------|------|
| X 轴 | **1** | ZDT_X42 / X57 | 水平横向驱动 |
| Y 轴 | **2** | ZDT_X42 / X57 | 水平纵向驱动 |
| Z 轴 | **3** | ZDT_X28 / X42 | 垂直升降 |
| R 轴 (旋转) | **4** | ZDT_X28 | 吸嘴旋转 (360° 连续) |

> 每台驱动器需通过 OLED 菜单将 `ID_Addr` 分别设为 1–4。

## 3. 控制模式

### 3.1 基本原则

本执行器采用 **高精度开环位置控制**，与例程中基于误差反馈的速度环控制 (视觉追踪) 有本质区别：

| 特性 | 视觉追踪例程 (旧) | 本执行器 (新) |
|------|-----------------|--------------|
| 控制模式 | 速度环 (0xF6) | **位置模式 (0xFD)** |
| 反馈来源 | 视觉像素偏差 | 驱动器编码器 (开环使用) |
| 控制律 | PID / 比例速度 | **直接给定目标位置** |
| 适用场景 | 连续跟踪运动目标 | **点到点精确定位** |
| 精度依赖 | 视觉标定精度 | **机械标定精度** |

### 3.2 开环位置控制工作流

```
上位机 ──→ 计算目标位置(°)
         │
         ↓ 发送 0xFD 绝对位置命令
    ZDT 驱动器 ──→ 电机运行到目标角度
         │
         ↓ 读取 0x36 确认到位
    上位机 ──→ 验证状态 (0x3A 到位标志)
         │
         ↓ 到位后执行下一步
```

### 3.3 设置开环模式

每台驱动器需通过 OLED 或 `zdt_SetCtrlMode()` 设置为开环模式：

```c
// 代码示例：设为开环模式
zdt_SetCtrlMode(true, ZDT_MODE_OPENLOOP);   // mode = 1
```

> **为什么不用闭环模式？**  
> 本执行器是笛卡尔坐标结构，各轴独立运动，不需要闭环纠偏。开环模式下驱动器仍会利用编码器做失步检测，但不会主动修正位置。这样避免了闭环模式下 PID 参数调节的复杂性，同时保持足够精度。

## 4. 坐标系统与单位约定

### 4.1 旋转轴 (R, ID=4)

- **输入单位**: 度 (°)
- **输出单位**: 度 (°)
- **方向**: **逆时针 (CCW) 为正方向**
- **范围**: 0–360° 连续旋转
- **控制方式**: 直接使用 ZDT 位置模式 (0xFD) 的绝对/相对定位

旋转轴不需要距离-角度映射，可直接用驱动器原生角度单位控制：

```c
// R 轴：逆时针旋转 90°
zdt_PositionModeAbs(ZDT_DIR_CCW, rpm, accel, 90 * 10, true);
// 注意: 0xFD 命令中位置单位为 0.1°，因此 90° = 900
```

### 4.2 位移轴 (X, Y, Z, ID=1/2/3)

- **输入单位**: 毫米 (mm) — 目标移动距离
- **输出单位**: 度 (°) — 电机需要转过的角度
- **方向**: 正距离 → 正方向转动；负距离 → 反方向转动
- **需要轴映射函数**: `distance_mm → motor_degrees`

#### 轴映射函数

每个轴的距离-角度映射关系不同，由机械传动结构决定：

```
θ = distance_mm × K_axis
```

其中 `K_axis` 是标定系数，单位 `°/mm`。

| 轴 | 传动方式 | 标定系数 `K` | 说明 |
|----|---------|-------------|------|
| X | 同步带/丝杆 | `K_X` (待标定) | 需实测 |
| Y | 同步带/丝杆 | `K_Y` (待标定) | 需实测 |
| Z | 丝杆/螺杆 | `K_Z` (待标定) | 需实测 |

#### 标定方法

1. 在轴上标记一个起始位置，记录电机编码器角度 `θ_start`
2. 用尺规测量移动实际距离 `d` (mm)
3. 读取电机最终角度 `θ_end`
4. 计算 `K = (θ_end - θ_start) / d`
5. 重复多次取平均值

```python
def calibrate_axis(motor_id):
    """标定一个轴的距离-角度映射系数 K (°/mm)"""
    # 1. 读取初始角度
    theta_start = read_position(motor_id)
    # 2. 移动一个已知距离
    move_to_position(motor_id, target_mm)
    # 3. 读取结束角度
    theta_end = read_position(motor_id)
    # 4. 计算 K
    K = (theta_end - theta_start) / measured_distance_mm
    return K
```

#### 工程实现

在实际代码中，封装一个统一的轴抽象层：

```python
class LinearAxis:
    """位移轴抽象 (X/Y/Z)"""
    def __init__(self, motor_id: int, K: float):
        self.id = motor_id
        self.K = K  # °/mm, 标定系数
    
    def move_to(self, target_mm: float):
        """移动到目标绝对位置 (mm)"""
        degrees = target_mm * self.K
        # 转换为 0.1° 单位，调用 ZDT 位置模式
        send_position_abs(self.id, int(degrees * 10))
    
    def move_rel(self, delta_mm: float):
        """相对移动 (mm)"""
        delta_deg = delta_mm * self.K
        send_position_rel(self.id, int(delta_deg * 10))
    
    def read_position_mm(self) -> float:
        """读取当前位置 (mm)"""
        deg = read_position(self.id)  # °
        return deg / self.K
```

## 5. 电磁铁吸嘴控制

电磁铁替代 3D 打印机的挤出喷嘴，通过 GPIO / 继电器控制通断：

| 状态 | 动作 |
|------|------|
| 通电 | 吸取拼图碎片 |
| 断电 | 释放拼图碎片 |

控制信号可由主控 MCU 的 GPIO 引脚输出，或通过 ZDT 驱动器的扩展 IO 控制。

> ⚠ **注意**: 电磁铁吸合/释放有一定延迟，建议在动作后加入 50–100ms 延时再进行下一步运动。

## 6. 通信架构

### 6.1 总线拓扑

4 台 ZDT 驱动器挂载在同一条 **RS485 总线** 上：

```
                    ┌──────────┐
                    │  主控    │
                    │ (MCU/PC) │
                    └────┬─────┘
                         │ RS485 (A/B)
          ┌──────────────┼──────────────┐
          │              │              │
     ┌────┴────┐   ┌────┴────┐   ┌────┴────┐
     │ X ID:1  │   │ Y ID:2  │   │ Z ID:3  │ ...
     └─────────┘   └─────────┘   └─────────┘
```

### 6.2 地址路由

所有命令通过 **地址字节** 区分目标电机：

| 目标 | 发送帧 (示例: 读位置) |
|------|---------------------|
| X 轴 | `01 36 6B` |
| Y 轴 | `02 36 6B` |
| Z 轴 | `03 36 6B` |
| R 轴 | `04 36 6B` |

### 6.3 命令间隔

由于四台驱动器共享总线，需注意：

- 同一驱动器命令间隔 ≥ **5ms**
- 切换目标地址后，建议等待 ≥ **2ms** 让驱动器处理完上一帧
- 批量读取时，依次发地址 1→2→3→4 轮询

## 7. 安全与限位

### 7.1 软件限位

为避免碰撞损坏机械结构，应在软件中实现各轴软限位：

| 轴 | 最小限位 (mm) | 最大限位 (mm) |
|----|--------------|--------------|
| X | `X_MIN` (待定义) | `X_MAX` (待定义) |
| Y | `Y_MIN` (待定义) | `Y_MAX` (待定义) |
| Z | `Z_MIN` (待定义) | `Z_MAX` (待定义) |
| R | 0° | 360° (或连续) |

### 7.2 回零流程

上电后执行回零操作，建立机械原点：

```
1. Z 轴上升至安全高度
2. X/Y 分别回零 (碰限位开关或霍尔传感器)
3. R 轴回零 (旋转到标记位置)
4. 记录各轴零点角度
5. Z 轴下降到工作平面
```

### 7.3 堵转检测

开环模式下应定期读取状态标志 (`0x3A`)，检测堵转位：

```c
uint8_t flags;
zdt_ReadStatusFlags(&flags);
if (flags & ZDT_FLAG_STALL) {
    // 堵转！立即停止所有轴并报警
    emergency_stop();
}
```
