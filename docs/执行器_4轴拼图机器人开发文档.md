# 4 轴拼图机器人执行器 — 开发文档

> **项目**: 电赛 E 题 — 拼图装置  
> **硬件**: ZDT_X_V2 闭环步进驱动器 × 4 + 电磁铁吸嘴  
> **主控**: 树莓派 5（生产）/ PC Windows（测试），均用 Python  
> **协议**: 自定义 0x6B 协议 (Emm_V5.0) / Modbus-RTU  
> **控制模式**: 高精度开环位置控制（非速度环）  
> **最后更新**: 2026-07-30

---

## 1. 系统概述

执行器仿照 3D 打印机运动结构设计，拥有 **4 个自由度**：

| 轴 | 功能 | 说明 |
|----|------|------|
| **X 轴** | 水平横向运动 | 左右移动吸嘴 |
| **Y 轴** | 水平纵向运动 | 前后移动吸嘴 |
| **Z 轴** | 垂直升降运动 | 抬起/放下吸嘴 |
| **R 轴 (旋转)** | 吸嘴旋转 | 调整拼图碎片角度 |

末端执行器将 3D 打印机的挤出喷嘴替换为 **电磁铁**，用于吸取和释放拼图碎片。

```
                     ┌─────────────┐
                     │  Z (升降)   │
                     │  电机 ID:3  │
                     │ (需保持力矩) │
                     └──────┬──────┘
                            │
              ┌─────────────┴─────────────┐
              │   R (旋转) 电机 ID:4      │
              │  -240° ~ +240°, 逆时针为正 │
              │  每次执行后回初始位置       │
              └─────────────┬─────────────┘
                            │
                     ┌──────┴──────┐
                     │   电磁铁    │
                     │  (吸取碎片) │
                     └─────────────┘
              ──── X 轴 (ID:1) ────→ (带齿条皮带)
              ════ Y 轴 (ID:2) ════→ (带齿条皮带)
```

## 3. 控制模式

### 3.1 基本原则

本执行器采用 **高精度开环位置控制**，与例程中基于误差反馈的速度环控制 (视觉追踪) 有本质区别：

| 特性 | 视觉追踪例程 (旧) | 本执行器 (新) |
|------|-----------------|--------------|
| 控制模式 | 速度环 (0xF6) | **位置模式 (0xFD)** |
| 反馈来源 | 视觉像素偏差 | 驱动器编码器 (开环使用) |
| 控制律 | PID / 比例速度 | **直接给定目标位置** |
| 适用场景 | 连续跟踪运动目标 | **点到点精确定位** |
| 精度依赖 | 视觉标定精度 | **机械标定精度** |

### 3.2 开环位置控制工作流

```
上位机 ──→ 计算目标位置(°)
         │
         ↓ 发送 0xFD 绝对位置命令
    ZDT 驱动器 ──→ 电机运行到目标角度
         │
         ↓ 读取 0x36 确认到位
    上位机 ──→ 验证状态 (0x3A 到位标志)
         │
         ↓ 到位后执行下一步
```

### 3.3 开环稳定性保障

#### 机械传动：带齿条皮带

X/Y 轴采用 **带齿条皮带** 传动，电机输出轴齿轮与皮带齿形啮合：

- **无打滑**：齿形啮合保证位移与电机旋转严格同步
- **精度来源**：位移精度完全取决于齿轮分度圆直径与皮带齿距的制造公差
- **标定原理**：齿形啮合意味着 `角度 ↔ 距离` 为严格线性关系，一次标定即可

#### 传动示意图

```
  电机输出轴齿轮 (齿数 Z)
        ⚙
        ▚▚▚▚▚▚▚▚▚  带齿皮带 (固定齿距 P)
   ─────▚▚▚▚▚▚▚▚▚─────→ 移动方向

   每转位移 = π × D_gear = Z × P
```

---

### 3.3 设置开环模式

每台驱动器需通过 OLED 或 `zdt_SetCtrlMode()` 设置为开环模式：

```c
// 代码示例：设为开环模式
zdt_SetCtrlMode(true, ZDT_MODE_OPENLOOP);   // mode = 1
```

> **为什么不用闭环模式？**  
> 本执行器是笛卡尔坐标结构，各轴独立运动，不需要闭环纠偏。开环模式下驱动器仍会利用编码器做失步检测，但不会主动修正位置。这样避免了闭环模式下 PID 参数调节的复杂性，同时保持足够精度。

## 4. 坐标系统与单位约定

### 4.1 旋转轴 (R, ID=4)

- **输入单位**: 度 (°)
- **输出单位**: 度 (°)
- **方向**: **逆时针 (CCW) 为正方向**
- **旋转范围**: **−240° ~ +240°**（不可连续旋转，电磁铁线缆会缠绕）
- **归位策略**: 每次旋转执行完毕后，R 轴 **必须回到 0° 初始位置**，避免线缆累计缠绕
- **控制方式**: 直接使用 ZDT 位置模式 (0xFD) 的绝对/相对定位

旋转轴不需要距离-角度映射，可直接用驱动器原生角度单位控制：

```c
// R 轴：逆时针旋转 90°
zdt_PositionModeAbs(ZDT_DIR_CCW, rpm, accel, 90 * 10, true);
// 注意: 0xFD 命令中位置单位为 0.1°，因此 90° = 900
```

> ⚠ **R 轴工作流**:  
> `读取当前位置 → 计算目标角度 → 旋转 → 执行拼图动作 → 回到 0°`  
> 如果连续多次旋转，每次结束后回到 0° 后再旋转下一次，避免超出 ±240° 限位。

### 4.2 位移轴 (X, Y, Z, ID=1/2/3)

- **输入单位**: 毫米 (mm) — 目标移动距离
- **输出单位**: 度 (°) — 电机需要转过的角度
- **方向**: 正距离 → 正方向转动；负距离 → 反方向转动
- **方向修正**: Y 轴和 R 轴的正方向与编码器递增方向相反，发送命令时需取反方向位（详见下方标定结果）
- **需要轴映射函数**: `distance_mm → motor_degrees`

#### 轴映射函数

每个轴的距离-角度映射关系不同，由机械传动结构决定：

```
θ = distance_mm × K_axis
```

其中 `K_axis` 是标定系数，单位 `°/mm`。

| 轴 | 传动方式 | 标定系数 `K` | 方向系数 | 说明 |
|----|---------|-------------|---------|------|
| X | 带齿条皮带 | **`8.9980 °/mm`** ✅ | **+1** | 正方向＝编码器递增 |
| Y | 带齿条皮带 | **`8.9394 °/mm`** ✅ | **−1** | 正方向＝编码器递减，需取反 |
| Z | 丝杆/螺杆 (无自锁) | **两点定位** ✅ | **+1** | 放下 0° / 抬升 73.9° |
| R | 直接旋转 | `1.0` (角度) ✅ 已验证 | **−1** | 逆时针90°→读数-90.1°, 偏差0.1° |

#### 正方向标定结果

2026-07-30 通过手动推动实测，各轴正方向对应的编码器变化如下：

| 轴 | 正方向推动 | 位置变化 | 编码器变化 | 方向一致性 |
|----|-----------|---------|-----------|-----------|
| X | → 正方向 | +402.3° | **+7726** | ✅ 一致（递增） |
| Y | → 正方向 | −409.0° | **−8932** | ⚠️ **反向（递减）** |
| Z | ↑ 正方向 | +94.5° | **+17207** | ✅ 一致（递增） |
| R | ↺ 逆时针 | −135.9° | **−24738** | ⚠️ **反向（递减）** |

##### 软件方向修正

Y 轴和 R 轴的编码器变化方向与正方向相反，在驱动代码中做如下修正：

- **Y 轴** (`ID=2`): 位置命令的方向位取反（`CW ↔ CCW`），或位置值取负
- **R 轴** (`ID=4`): 角度命令的方向位取反，确保逆时针旋转对应正角度增量

代码中通过 `dir_sign` 系数统一处理：

```python
# 各轴方向系数: +1 正方向对应编码器递增, -1 正方向对应编码器递减
DIR_SIGN = {1: +1, 2: -1, 3: +1, 4: -1}
# 使用方式: 实际方向 = DIR_SIGN[axis] × 目标方向
```

> **背景**: 方向不一致通常由电机相线接线顺序或机械传动结构导致，软件取反是正常做法，不影响精度。

#### 标定方法

##### 操作流程

1. **上电使能**，电磁铁保持断电（无负载）
2. 在皮带或滑块的 **起始位置做物理标记**
3. **释放力矩** (`zdt_Enable(false)`) → 手动将滑块推到大致中间位置
4. 重新 **保持力矩** (`zdt_Enable(true)`)，读取当前编码器角度 `θ_start`
5. 使用位置模式向 **正方向** 移动一段预期距离（如发命令走 1000 个 0.1° 单位）
6. 到位后读取最终角度 `θ_end`
7. **用尺规测量** 滑块实际移动的物理距离 `d` (mm)
8. 计算标定系数 `K = (θ_end - θ_start) / d` (°/mm)

```
物理标记          θ_start               θ_end
   │                  │                    │
   ├──────────────────┼────────────────────┼──→
   │← 物理测量 d mm →│
   │←──── 编码器角度 Δθ ────→│

   K = Δθ / d   (°/mm)
```

9. 重复 3–5 次取平均值，消除测量误差

```python
def calibrate_axis(motor_id):
    """标定一个轴的距离-角度映射系数 K (°/mm)
    
    流程：使能 → 标记 → 释放 → 手动推至中间 → 保持 → 读角度
          → 正方向移动 → 读角度 → 尺测实际距离 → 算K
    """
    # 1. 使能电机，读取当前位置（起始标记点）
    enable(motor_id, True)
    theta_start = read_position_deg(motor_id)   # °
    
    # 2. 正方向移动一个已知脉冲量
    target_deg = 100.0   # 先设定走 100° 的脉冲
    move_relative(motor_id, target_deg)          # 相对移动
    wait_until_idle(motor_id)
    theta_end = read_position_deg(motor_id)      # °
    delta_deg = theta_end - theta_start          # °
    
    # 3. 实际测量移动距离 (需要人工用尺量!)
    measured_mm = float(input(f"请测量轴{motor_id}实际移动距离(mm): "))
    
    # 4. 计算标定系数
    K = delta_deg / measured_mm                  # °/mm
    return K
```

#### 工程实现

在实际代码中，封装一个统一的轴抽象层：

```python
# 各轴方向系数 (2026-07-30 实测标定)
# +1: 正方向→编码器递增  |  -1: 正方向→编码器递减 (需取反)
DIR_SIGN = {1: +1, 2: -1, 3: +1, 4: -1}


class LinearAxis:
    """位移轴抽象 (X/Y/Z)"""
    def __init__(self, motor_id: int, K: float):
        self.id = motor_id
        self.K = K            # °/mm, 标定系数
        self.sign = DIR_SIGN.get(motor_id, 1)  # 方向系数
    
    def move_to(self, target_mm: float):
        """移动到目标绝对位置 (mm)"""
        degrees = target_mm * self.K * self.sign
        send_position_abs(self.id, int(degrees * 10))
    
    def move_rel(self, delta_mm: float):
        """相对移动 (mm)"""
        delta_deg = delta_mm * self.K * self.sign
        send_position_rel(self.id, int(delta_deg * 10))
    
    def read_position_mm(self) -> float:
        """读取当前位置 (mm)"""
        deg = read_position(self.id)  # °
        return deg / self.K * self.sign
```

## 5. Z 轴力矩管理

### 5.1 问题说明

Z 轴使用 **无自锁丝杆/螺杆** 传动，断电后电机自由旋转，电磁铁及滑台在重力作用下自然下垂。

### 5.2 力矩策略

| 阶段 | Z 轴状态 | 说明 |
|------|---------|------|
| 空闲 / 等待 | **释放力矩** (`zdt_Enable(false)`) | Z 轴自然下垂，省电、避免温升 |
| X/Y 移动 | **释放力矩** | Z 轴已在上位，无需保持 |
| 吸取/释放碎片 | **释放力矩** | 电磁铁已接触碎片，Z 轴靠自重压紧 |
| **搬运过程** | **保持力矩** (`zdt_Enable(true)`) | Z 轴抬升，将碎片提起离开台面 |
| 拍照/视觉检测 | **保持力矩** | 碎片悬空，方便相机拍摄 |

### 5.3 Z 轴两点控制参数

Z 轴为两点定位控制，无需标定 K 系数：

| 状态 | 位置 (°) | 驱动器单位 (0.1°) |
|------|---------|-----------------|
| **放下** (`Z_DOWN`) | **0.0°** | `0` |
| **抬升** (`Z_UP`) | **73.9°** | `739` |

```python
# 控制示例
zdt_PositionModeAbs(dir, rpm, accel, Z_UP * 10, True)    # 抬升
zdt_PositionModeAbs(dir, rpm, accel, Z_DOWN * 10, True)  # 放下
```

> 放下到位后应释放力矩 (`zdt_Enable(false)`)，避免无谓发热。

### 5.4 搬运时序

```
X/Y 定位到碎片上方 ──→ Z 下降至接触碎片
    │                     │
    │              电磁铁通电吸取
    │                     │
    │              等待 50ms 吸合
    │                     │
    ├── Z 抬升 (保持力矩) ──┤  ← 碎片离开台面
    │                     │
X/Y 移动到目标位置 ──→ Z 下降 (释放力矩)
    │                     │
    │              电磁铁断电释放
    │                     │
    │              等待 50ms 释放
    │                     │
    └── Z 保持力矩解除 ──┘  ← 空闲下垂
```

> ⚠ Z 轴使能/失使能切换时注意：
> - **使能** (`zdt_Enable(true)`): 力矩恢复瞬间电机会轻微抖动，建议 50ms 后再发运动命令
> - **失使能** (`zdt_Enable(false)`): 电机瞬间失去力矩，确保下方无碰撞物

## 7. 电磁铁吸嘴控制

电磁铁替代 3D 打印机的挤出喷嘴，通过 GPIO / 继电器控制通断：

| 状态 | 动作 |
|------|------|
| 通电 | 吸取拼图碎片 |
| 断电 | 释放拼图碎片 |

控制信号可由主控 MCU 的 GPIO 引脚输出，或通过 ZDT 驱动器的扩展 IO 控制。

> ⚠ **注意**: 电磁铁吸合/释放有一定延迟，建议在动作后加入 50–100ms 延时再进行下一步运动。

## 8. 通信架构

### 6.1 总线拓扑

4 台 ZDT 驱动器挂载在同一条 **RS485 总线** 上：

```
                    ┌──────────────┐
                    │  主控        │
                    │ 树莓派5/PC   │
                    └────┬─────┘
                         │ RS485 (A/B)
          ┌──────────────┼──────────────┐
          │              │              │
     ┌────┴────┐   ┌────┴────┐   ┌────┴────┐
     │ X ID:1  │   │ Y ID:2  │   │ Z ID:3  │ ...
     └─────────┘   └─────────┘   └─────────┘
```

### 6.2 地址路由

所有命令通过 **地址字节** 区分目标电机：

| 目标 | 发送帧 (示例: 读位置) |
|------|---------------------|
| X 轴 | `01 36 6B` |
| Y 轴 | `02 36 6B` |
| Z 轴 | `03 36 6B` |
| R 轴 | `04 36 6B` |

### 6.3 命令间隔

由于四台驱动器共享总线，需注意：

- 同一驱动器命令间隔 ≥ **5ms**
- 切换目标地址后，建议等待 ≥ **2ms** 让驱动器处理完上一帧
- 批量读取时，依次发地址 1→2→3→4 轮询

## 9. 安全与限位

### 9.1 软件限位

为避免碰撞损坏机械结构，应在软件中实现各轴软限位：

| 轴 | 最小限位 (mm) | 最大限位 (mm) |
|----|--------------|--------------|
| X | `X_MIN` (待定义) | `X_MAX` (待定义) |
| Y | `Y_MIN` (待定义) | `Y_MAX` (待定义) |
| Z | `Z_MIN` (待定义) | `Z_MAX` (待定义) |
| R | −240° | +240° |

### 9.2 回零流程

上电后执行回零操作，建立机械原点：

```
1. Z 轴上升至安全高度
2. X/Y 分别回零 (碰限位开关或霍尔传感器)
3. R 轴回零 (旋转到标记位置)
4. 记录各轴零点角度
5. Z 轴下降到工作平面
```

### 9.3 过流保护（限流）

实时监测电机相电流，防止堵转或机械卡死造成损坏：

| 参数 | 阈值 | 说明 |
|------|------|------|
| 最大相电流 | **1000 mA** | 超过此值认为有堵转风险 |
| 检测命令 | `0x26` (读取实际相电流) | 单位 mA |
| 响应动作 | **立即释放力矩** `zdt_Enable(false)` | 并报警 |

```python
def check_overcurrent(addr):
    current_ma = read_actual_current(addr)  # 0x26
    if current_ma > 1000:
        enable_motor(addr, False)           # 释放力矩
        log_error(f'电机 {addr} 过流: {current_ma}mA > 1000mA，已保护')
        return True
    return False
```

> 正常运行时相电流通常在 100–500mA 范围（取决于负载和转速）。
> 超过 1000mA 通常意味着机械卡死、滑轨到头或严重摩擦。

### 9.4 限位保护

在软件中实现各轴软限位，防止电机驱动超过机械行程范围：

| 轴 | 下限位 | 上限位 | 说明 |
|----|--------|--------|------|
| X | `X_MIN` (待测量) | `X_MAX` (待测量) | 滑轨物理长度决定 |
| Y | `Y_MIN` (待测量) | `Y_MAX` (待测量) | 滑轨物理长度决定 |
| Z | 0° (放下) | 73.9° (抬升) | ✅ 已标定 |
| R | −240° | +240° | ✅ 已定义 |

每次发送位置命令前，先校验目标位置是否在限位范围内：

```python
LIMITS = {
    1: (-9999, 9999),   # X: (待测量)
    2: (-9999, 9999),   # Y: (待测量)
    3: (0, 73.9),       # Z: 0°(放下) ~ 73.9°(抬升)
    4: (-240, 240),     # R: -240° ~ +240°
}

def check_limits(addr, target_deg):
    lo, hi = LIMITS[addr]
    if not (lo <= target_deg <= hi):
        raise ValueError(f'电机 {addr} 目标 {target_deg:.1f}° 超出限位 [{lo}, {hi}]')
```

> X/Y 的限位范围需在安装完成后实测滑轨行程并填入。
> Z 轴和 R 轴限位已由标定结果确定。

### 9.5 温度检测

监测驱动器/电机温度，过热时保护：

| 参数 | 阈值 | 说明 |
|------|------|------|
| 最高温度 | **50 °C** | 超过此值认为过热 |
| 检测命令 | `0x39` (读取温度) | 单位 °C |
| 响应动作 | **释放力矩** + 停止运动 | 等待冷却后恢复 |

```python
def check_temperature(addr):
    temp_c = read_temperature(addr)  # 0x39
    if temp_c > 50:
        enable_motor(addr, False)
        log_error(f'电机 {addr} 过热: {temp_c}°C > 50°C，已保护')
        return True
    return False
```

> 室温下电机空闲温度约 30°C，连续运动通常在 35–45°C。
> 超过 50°C 说明负载过大、散热不良或堵转。

### 9.6 安全巡检周期

建议在主循环中定期执行安全巡检：

```python
def safety_check():
    """对所有电机执行安全巡检 (建议每 500ms 调用一次)"""
    for addr in [1, 2, 3, 4]:
        if check_overcurrent(addr):   # 过流 → 释放 + 报警
            continue
        if check_temperature(addr):   # 过热 → 释放 + 报警
            continue
        # 堵转检测 (可选, 开环模式下驱动器自身也会检测)
        flags = read_status_flags(addr)
        if flags & 0x04:              # 堵转标志
            enable_motor(addr, False)
            log_error(f'电机 {addr} 堵转!')
```

from actuator import Actuator

#### 核心方法

| 方法 | 说明 | 速度/距离换算 |
|------|------|-------------|
| `move_to(x, y, rpm, accel)` | XY 直线插补，按距离比例分配速度 | 自动 ×K ×DIR_SIGN |
| `z_up(rpm, accel)` | Z 抬升 + 保持力矩 | 绝对定位到 73.9° |
| `z_down(rpm, accel)` | Z 放下 + 释放力矩 | 绝对定位到 0° |
| `rotate(deg, rpm, accel)` | R 轴旋转到指定角度 | ±240° 限位检查 |
| `rotate_home(rpm, accel)` | R 轴回 0° | — |
| `home_all(rpm, accel)` | 全部轴归零 (R→XY→Z) | — |
| `pickup()` | 电磁铁通电 (GPIO 预留) | — |
| `release()` | 电磁铁断电 (GPIO 预留) | — |
| `get_position()` | 返回 `(x_mm, y_mm, z_deg, r_deg)` | — |
| `status_report()` | 生成完整状态文本 | — |
| `safety_check(addr)` | 安全巡检 (过流/过热/堵转) | 自动调用 |
| `close()` | 关闭串口 | — |

#### XY 直线插补

`move_to()` 自动计算速度分配，确保两轴同时到达：

```
较长轴: speed = min(requested, MAX_RPM=40)
较短轴: speed = max_speed × (短距离 / 长距离)
```

例: `act.move_to(150, 130, rpm=30)`
- X (150mm): 30 RPM ← 较长轴
- Y (130mm): 30 × 130/150 = **26 RPM** ← 按比例减速

#### 安全保护

每次移动前后自动调用 `safety_check()`，监测：

| 保护项 | 阈值 | 触发动作 |
|--------|------|---------|
| 过流 (`0x26`) | >1000 mA | 释放力矩 + 抛异常 |
| 过热 (`0x39`) | >50 °C | 释放力矩 + 抛异常 |
| 堵转 (`0x3A`) | bit2=1 | 释放力矩 + 抛异常 |

#### 使用示例

```python
act = Actuator('COM8')

# 吸取 → 搬运 → 放置 完整流程
act.move_to(150, 130, rpm=30)   # XY 联动
act.z_up()                       # Z 抬升
act.pickup()                     # 电磁铁吸取
act.move_to(50, 80, rpm=25)     # 搬运到目标
act.z_down()                     # Z 放下 (自动释放力矩)
act.release()                    # 电磁铁释放

act.home_all()                   # 全部归零
act.close()
```
